# Sinking Protocol

Moment when it is important to suddenly abandon current workstation that can be compromised, collect all results of work progress on projects, secure them on dedicated to this purpose huge hard drive and reinstall operating system of currently used machine. this is procedure of ASAP matter to ensure safety and security against threat of being compromised. If it is possible to migrate workspace setups for new environment customizing without danger of contamination it is worth to list all available toolsets and programs by for example extraction of terminal history stories
