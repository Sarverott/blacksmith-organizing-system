# Bootstrapping Protocol

Makes the workshop whole: `.BOS/` with setup, data, nests (+ index and
manifest), `workshop.json` and `Taskfile.yaml`; devarmory (+ manifest), forge,
craftbook (+ scrapnotes) and archive; `AGENTS.md` and `CLAUDE.md` at the root.
It creates only what is missing and never overwrites. With `--dry-run` it only plans.
