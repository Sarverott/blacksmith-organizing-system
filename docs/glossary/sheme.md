# Sheme

> DRAFT. Spelled *sheme* (older *scheme*).

## What it is

Source material that isn't code, kept next to the projects it belongs with:

- images and graphics project files (e.g. GIMP)
- Blender and CAD project files, and their renders
- photos: they follow the same patterns of use
- notes and notebooks, playgrounds, live-code docs, VM or container sandboxes,
  partial ttystories, test areas
- some PDFs and other documents from outside sources (third-party authorship)
  kept for their reference value

The boundary: a layout template from a design program is a sheme. The code
that realizes that design is a [project](project.md) that uses the sheme as its
starting point.

## Why it exists

A lot of valuable work has no build or release. Shemes give it a proper home
in the scope, instead of loose folders.

## Where

Inside a [scope](scope.md).
